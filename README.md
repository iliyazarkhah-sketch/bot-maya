# ربات تلگرامی فروشگاه (ثبت سفارش + گفتگوی پشتیبانی)

## مراحل راه‌اندازی

### ۱. ساخت ربات در تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بزن و اسم و یوزرنیم ربات را انتخاب کن.
3. توکنی که می‌دهد را نگه دار (مثل `123456:ABC-DEF...`).

### ۲. پیدا کردن Chat ID خودت (ادمین)
1. به ربات [@userinfobot](https://t.me/userinfobot) پیام بده.
2. عدد Chat ID که برایت می‌فرستد را کپی کن.

### ۳. آپلود پروژه در Netlify
1. این پوشه را در یک ریپازیتوری گیت‌هاب آپلود کن (همون روشی که قبلاً با ربات پشتیبانی استفاده کردی).
2. در Netlify یک سایت جدید از روی این ریپازیتوری بساز.
3. در بخش **Site settings → Environment variables** دو متغیر زیر را اضافه کن:
   - `TELEGRAM_BOT_TOKEN` = توکن مرحله ۱
   - `ADMIN_CHAT_ID` = عدد چت آیدی مرحله ۲
4. در **Site settings → Blobs** مطمئن شو Netlify Blobs فعال است (پیش‌فرض روی اکثر پلن‌ها فعاله).
5. سایت را دیپلوی کن.

### ۴. وصل کردن Webhook تلگرام به آدرس Netlify
بعد از دیپلوی، آدرس فانکشن این شکلی می‌شود:
```
https://YOUR-SITE-NAME.netlify.app/.netlify/functions/bot
```
این آدرس را در مرورگر یا با curl به این شکل صدا بزن (به‌جای مقادیر داخل `<>` مقدار واقعی بگذار):
```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://YOUR-SITE-NAME.netlify.app/.netlify/functions/bot
```
اگر پیام `{"ok":true,"result":true,...}` برگشت، وصل شدن Webhook موفق بوده.

### ۵. تست
- با اکانت شخصی (غیر ادمین) به ربات `/start` بزن → باید منوی «گفتگو با فروشگاه / ثبت سفارش» را ببینی.
- با اکانتی که Chat ID آن را در `ADMIN_CHAT_ID` گذاشتی `/start` بزن → باید «پنل مدیریت فروشگاه» را ببینی.

## نکات مهم دربارهٔ رفتار ربات
- **گفتگو با فروشگاه:** پیام مشتری برای ادمین با دکمهٔ «پاسخ» ارسال می‌شود. از دومین پیام مشتری به بعد، دکمهٔ «پایان گفتگو» هم کنار «پاسخ» ظاهر می‌شود. با پایان گفتگو، مشتری دیگر نمی‌تواند پیام بدهد تا وقتی دوباره روی «شروع گفتگوی مجدد» بزند.
- **ثبت سفارش:** مراحل (ارسال اطلاعات → ارسال عکس فیش) اجباری است و در این بخش دکمهٔ بازگشت وجود ندارد، طبق درخواستت.
- **پنل ادمین:** با «مشاهده تمام سفارش‌ها» لیست سفارش‌ها را می‌بینی؛ هر سفارش تا وقتی تایید نشده فقط دکمهٔ «تایید سفارش» دارد. بعد از تایید، چهار دکمهٔ وضعیت (آماده‌سازی / بسته‌بندی / تحویل به پستچی / ارسال کد رهگیری) ظاهر می‌شود. هر دکمه بعد از زدن، متنش به «برای کاربر ارسال شد» تغییر می‌کند و دیگر قابل کلیک نیست.
- **دکمهٔ بازگشت:** زیر همهٔ پیام‌ها (چه ادمین چه مشتری) هست، به‌جز مراحل ثبت سفارش برای مشتری.

## یک نکتهٔ فنی برای توسعهٔ بعدی
دکمهٔ «بازگشت» فعلاً همیشه به منوی اصلی (مشتری یا ادمین) برمی‌گردد، نه دقیقاً «یک مرحله قبل‌تر» در تمام حالت‌ها — چون پیاده‌سازی یک استک کامل تاریخچه برای هر مکالمه پیچیدگی زیادی اضافه می‌کند. اگر لازم داری که در جاهای خاصی (مثلاً از داخل جزئیات یک سفارش) دقیقاً به مرحلهٔ قبلی‌تر برگردد، بگو تا برایت اضافه کنم.
